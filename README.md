# 🐍 PyGame Snake

A classic Snake game built with **Python** and **Pygame**.

## About

PyGame Snake is a recreation of the classic Snake arcade game.

Control the snake, collect food, grow longer, and avoid collisions. The project is developed in Python using the Pygame library.

## Installation

**1. Clone the repository**

```bash
git clone https://github.com/CleverJoe09/PyGame-Snake.git
cd PyGame-Snake
```

**2. Create a virtual environment**

```powershell
python -m venv .venv
```

**3. Activate the environment**

```powershell
.venv\Scripts\activate
```

**4. Install dependencies**

```powershell
python -m pip install pygame
```

**5. Start the game**

```powershell
python main.py
```
